# Dynamic Toggle Navigation

## About the Project
Dynamic Toggle Navigation is a responsive navigation menu built using HTML, CSS, and JavaScript. It provides a smooth hamburger menu animation, mobile-friendly drawer transitions, interactive navigation links, and active and hover states.

## Features
- Responsive desktop and mobile navigation
- Animated hamburger menu toggle
- Smooth CSS transitions
- Interactive navigation links
- Active link highlighting
- Close menu with Escape key
- Modern and clean user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation and Event Listeners)

## Learning Outcomes
This project demonstrates DOM manipulation, event handling, CSS animations, responsive web design, and interactive user interface development.

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
